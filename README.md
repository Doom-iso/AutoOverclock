# AutoOverclock
python scipt on version 3.11 i tested this with a 7600x cpu and a 5060 and worked smoothly it checks temperature and usage of cpu and gpu and overclocks or undervolts approprietly, also changes fan speeds.
To use you have to install
psutil
nvidia-ml-py
pythonnet
LibreHardwareMonitorLib.dll and HidSharp.dll in C:\LibreHardwareMonitor
ryzenadj.exe in C:\ryzenadj, and the NVIDIA driver
